# 高级弹性模式实现任务

- [x] 1. 建立弹性策略框架与统一配置中心
  - 创建 `resilience` 目录与策略路由入口。
  - 定义策略配置模型、校验与热更新机制。
  - 建立关键外部调用与策略绑定清单。
  _需求追溯: R7.AC1, R7.AC2, R7.AC4_

- [x] 2. 实现 Retry 策略（tenacity）
  - 对可重试异常实现指数退避 + 抖动。
  - 支持最大重试、延迟上下限参数。
  - 失败后保留原始异常并附加重试上下文。
  _需求追溯: R2.AC1, R2.AC2, R2.AC3, R2.AC4_

- [x] 3. 实现 Circuit Breaker 状态机
  - 实现 CLOSED/OPEN/HALF_OPEN 状态切换逻辑。
  - 支持失败阈值、冷却期与探测窗口。
  - 状态变更输出日志、指标与事件。
  _需求追溯: R1.AC1, R1.AC2, R1.AC3, R1.AC4_

- [x] 4. 实现 Bulkhead 并发隔离
  - 按依赖类型拆分独立并发池。
  - 支持超时等待、快速失败策略。
  - 暴露池利用率指标与告警。
  _需求追溯: R3.AC1, R3.AC2, R3.AC3, R3.AC4_

- [x] 5. 实现 Saga 引擎与补偿事务
  - 定义步骤 `action/compensate` 协议。
  - 持久化 Saga 实例与步骤状态。
  - 失败时逆序补偿，补偿失败进入人工介入状态。
  _需求追溯: R4.AC1, R4.AC2, R4.AC3, R4.AC4_

- [x] 6. 实现 Graceful Degradation 降级机制
  - Redis/缓存异常自动旁路。
  - 非关键依赖失败返回默认值并继续主流程。
  - 降级响应添加 `X-Degraded-Services` 标识。
  _需求追溯: R5.AC1, R5.AC2, R5.AC3, R5.AC4_

- [x] 7. 实现深度健康检查与运维接口
  - 新增 `/health/deep` 并发探测关键依赖。
  - 按关键依赖健康状态返回 200/503。
  - 新增熔断器与 Saga 运维查询接口并接入权限审计。
  _需求追溯: R6.AC1, R6.AC2, R6.AC3, R6.AC4, R7.AC1_

- [x] 8. 建立 CI 防回退与故障演练验收
  - CI 阻断未绑定弹性策略的关键外部调用。
  - 执行故障注入、降级恢复、性能回归与告警验证。
  - 发布弹性演练报告并归档。
  _需求追溯: R7.AC3, R7.AC4, R2.AC4, R1.AC4, R3.AC4_
