# 数据源接入管理 需求规格

## 简介
数据源接入管理模块为联邦查询系统的基础设施层，提供对外部数据源（MySQL、MongoDB、MinIO、PostgreSQL）的配置、连通性测试和生命周期管理功能。本模块遵循 PRD 3.2 节「数据源中心」的设计，采用统一表单 + 条件渲染方案（方案 A），后端使用单表 + `extra_config` JSON 字段存储各类型独有配置。

## 需求列表

### R1: 数据源列表展示与搜索
**用户故事:** 作为系统管理员，我希望在数据源中心页面查看所有已配置的数据源及其连接状态，以便快速掌握系统数据源全貌。
**验收标准 (EARS):**
- R1.AC1: WHEN 用户进入数据源中心页面 THEN 系统以分页表格展示数据源列表，包含字段：名称、类型（带图标）、连接地址（host:port）、连接状态（正常/异常）、说明、操作按钮（编辑、测试、删除）。
- R1.AC2: WHEN 用户在搜索栏输入关键词或选择类型筛选条件 THEN 列表按条件过滤并刷新展示。
- R1.AC3: WHEN 数据源列表为空 THEN 页面显示空状态引导，提示用户新增数据源。

### R2: 新增数据源（两步向导）
**用户故事:** 作为系统管理员，我希望通过两步向导新增数据源，以便根据数据源类型动态配置对应参数。
**验收标准 (EARS):**
- R2.AC1: WHEN 用户点击"新增"按钮 THEN 弹出向导第一步，展示 MySQL、MongoDB、MinIO、PostgreSQL 四种类型卡片（带图标和名称），用户选择后高亮并可点击"下一步"。
- R2.AC2: WHEN 用户完成第一步选择类型 THEN 进入第二步配置表单，展示通用字段（名称、主机、端口、用户名、密码、说明）及该类型的特有字段。
- R2.AC3: IF 数据源类型为 MySQL 或 PostgreSQL THEN 表单额外展示"数据库名"字段。
- R2.AC4: IF 数据源类型为 MongoDB THEN 表单额外展示"数据库名"和"认证源"字段。
- R2.AC5: IF 数据源类型为 MinIO THEN 表单将"数据库名"替换为"存储桶"，并额外展示"SSL 开关"字段。
- R2.AC6: WHEN 用户填写完配置并点击"保存" THEN 系统对必填字段进行校验，校验通过后将数据源配置持久化到数据库，密码使用 AES 加密存储。
- R2.AC7: WHEN 数据源名称与已有记录重复 THEN 保存失败并提示名称已存在。

### R3: 编辑数据源
**用户故事:** 作为系统管理员，我希望编辑已有数据源的配置信息，以便在连接参数变更时及时更新。
**验收标准 (EARS):**
- R3.AC1: WHEN 用户点击列表中某数据源的"编辑"按钮 THEN 弹出配置表单，数据源类型字段只读且不可更改，其余字段回填当前值。
- R3.AC2: WHEN 用户修改配置并点击"保存" THEN 系统校验必填字段后更新数据库记录。
- R3.AC3: IF 编辑时密码字段未修改（显示为掩码占位符） THEN 保存时不更新密码字段。

### R4: 删除数据源
**用户故事:** 作为系统管理员，我希望删除不再使用的数据源配置，以便保持数据源列表整洁。
**验收标准 (EARS):**
- R4.AC1: WHEN 用户点击"删除"按钮 THEN 弹出二次确认对话框，确认后执行软删除。
- R4.AC2: WHEN 删除成功 THEN 列表刷新移除该记录并显示成功提示。

### R5: 连通性测试
**用户故事:** 作为系统管理员，我希望在保存前或保存后测试数据源连通性，以便确认配置正确。
**验收标准 (EARS):**
- R5.AC1: WHEN 用户在新增/编辑表单中点击"测试连接"按钮 THEN 系统使用当前表单填写的参数发起异步连通性测试，测试期间按钮显示加载状态。
- R5.AC2: WHEN 连通性测试成功 THEN 显示绿色成功标识和"连接成功"提示。
- R5.AC3: WHEN 连通性测试失败 THEN 显示红色失败标识和具体错误信息（如连接超时、认证失败等）。
- R5.AC4: WHEN 用户在数据源列表点击"测试"按钮 THEN 使用已保存的配置发起连通性测试，并更新该数据源的连接状态字段。

### R6: 数据源详情查询
**用户故事:** 作为系统管理员，我希望查看单个数据源的完整配置详情，以便核实配置信息。
**验收标准 (EARS):**
- R6.AC1: WHEN 后端接收到按 ID 查询请求 THEN 返回数据源完整信息，密码字段不返回明文（返回空字符串或掩码）。
