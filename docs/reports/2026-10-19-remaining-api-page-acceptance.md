# RuoYi 剩余 API 与真实页面验收

> 后续补验：原先 35 个待执行操作已补齐本地或隔离存储证据，详见 [待执行项补验结果](2026-10-19-pending-api-page-acceptance.md)。下文保留上轮范围和执行记录。

本轮计划内的非仿真核心流程已完成验收，发现的问题已修复并复验。保留既有工作区改动，未提交、推送或发布。前端使用 ZXUI 源码直连，本地 MySQL、Redis、80 前端和 8088 后端保持运行。

## 修复结果

| 问题 | 处理与验证 |
| --- | --- |
| 新建工程的拓扑没有绑定初始版本 | 创建服务原本生成了版本 ID，但控制器响应和弹框事件丢失了它。新增 `ProjectCreatedModel` 明确返回初始版本 ID，前端透传到拓扑路由，同步 OpenAPI、生成类型和 Mock。真实页面新建工程 14 后保存的节点能在默认版本 14、克隆版本和导入副本中读取。 |
| 工程删除只隐藏工程，留下活动版本和拓扑 | 工程删除在同一事务内删除拓扑、标记关联版本删除；单版本删除清理对应拓扑。补齐拓扑所属工程、版本归属和固化状态检查。修复后本轮工程 13–16 的活动版本和拓扑均为 0；工程、版本、拓扑读取均返回 404。事务失败能回滚所有关联操作，参考工程不受影响。 |
| 固化、最后版本等业务约束可能返回 500 | 使用明确的资源冲突/不存在异常。真实验证：固化工程删除 409，固化拓扑保存 409，最后版本删除 409，错误归属及已删除工程的拓扑请求 404；解除固化后正常删除 204。 |
| 版本文件导出按钮没有发请求 | `ElForm` 缺少模型绑定，预验证阻断确认。绑定现有数据后，XML、Word、Excel 附录均能从页面下载。XML 可解析，Word 是现有 HTML `.doc` 格式；夹具设备没有协议数据，因此 Excel ZIP 按现有规则包含说明文件。 |
| 字典数据 Excel 表头错位 | 排序、标签、键值的中文映射写反。实际页面重新导出的数据逐列为“字典排序=7、字典标签=zxqa_export_label_mvenpxba、字典键值=stored_export_value”。旧错误文件保留为修复前证据。 |
| 岗位 Excel 导出为空白 | 非分页查询返回 ORM 对象，处理器却丢弃成空字典。直接使用读取模型已有的 `from_attributes` 能力。真实页面筛选“董事长”导出后，编号 1、编码 ceo、名称和正常状态均正确；没有修改参考岗位。 |
| 岗位、编辑读取和版本克隆重复显示错误 | 表单或编辑器负责本地错误，认证失败继续保留全局恢复提示。真实冲突从“弹框内 1 份 + 全局 1 份”变为“弹框内 1 份 + 全局 0 份”。克隆关闭后迟到结果不再影响新开编辑器。 |
| 调度日志把注册事件记成成功，遗漏一次性任务结果 | 只订阅实际执行、异常和错过执行事件；执行结束后从持久任务定义构建日志，显式事务保证读取后写入仍会提交。实际暂停任务手动运行后出现 `JobExecutionEvent` 成功记录，日志导出状态统一为成功/失败。 |
| 健康检查仍调用已移除的响应方法 | 修复六个健康/就绪入口的资源响应；真实均为 200，未初始化和严重异常的 503 分支有回归覆盖。 |
| 数据监控菜单是开发用 Mock 页面 | 复用现有连接池和查询统计 API 展示真实数据。刷新、单次网络失败提示和重试恢复均已实测。 |
| 服务监控磁盘容量错误 | 使用挂载点读取文件系统容量，复用一次采样。当前根卷由错误的 202.5KB 恢复为约 460.4GB。 |
| 系统接口文档空白 | 外部 CDN 加载与代理前缀不一致共同影响文档。固定 Swagger 官方静态资源版本并随前端交付，文档使用当前绝对 API 基址；真实渲染 30 个分组，执行 `/api/health` 返回 200。资源独立加载，代价是约 1.59MB 脚本及 184KB 样式。 |
| 生成器导入表首次打开为空、行点击不选择 | 等弹框打开完成再加载列表，直接持有实际表格引用。自动读取返回 200，行选择和取消选择完整通过，没有导入或修改现有表。 |
| 验证码初始化断网产生未处理异常 | 承接初始化请求拒绝，复用 HTTP 错误提示及已有点击刷新入口。单次断网后重试 200，无页面未处理异常，也没有提交登录。Mock 登录/退出同步补齐 Cookie 会话语义，真实客户端契约回归通过。 |

方案均复用已有领域模型、仓储、响应工厂和第三方能力，没有新增缓存框架或通用适配层。工程删除保留原有软删除策略，同时清理本轮确认属于工程聚合的版本状态和拓扑载荷；没有对其他历史工程做批量迁移。

## 本轮真实链路

- 系统配置、部门、岗位、菜单、字典类型/数据、公告：实际控件创建、校验、读取、修改与删除；在配置、部门、岗位等编辑器验证取消重开，菜单/公告验证失败重试，菜单验证读取后关闭重开不串值。相关导出按字段核对。
- 工程：新建→拖入已有设备→保存→版本图编辑回显；克隆、固化/解除固化、描述预览、单工程和批量 ZIP 导出、ZIP 导入副本、版本文件导出与删除。备用版本新增/读取/修改/删除明确记录为 API 验证，未冒充不存在的页面入口。
- 调度：自有暂停任务 8 的创建、修改、启停、手动运行、日志、筛选导出及删除。目标 `module_task.scheduler_test.job` 只输出参数和时间；为回归修复重复运行的均为此自有无副作用任务，没有执行既有任务。
- 监控与工具：在线用户、操作/登录/审计日志、服务看板、Redis 指标、缓存名称/键/自有配置值、数据库监控、接口文档、代码预览及数据库表清单、表单构建和 Vue 文件下载。导出的 Vue 模板通过编译器解析。
- 视图：1440×1000、1100×800。小视口岗位弹框的字段和确认/取消按钮完整可见；数据库页面无横向溢出；拓扑设备库、画布和保存入口可见。

不是所有目录项都标记为通过：169 个系统、工程、监控和工具操作中，93 项有本轮真实请求或页面记录，41 项指向历史模块证据，16 项属于明确排除的共享破坏性或既有表/文件系统写入，19 项为未实际执行的备用或旧入口。健康检查另外记录。历史证据不等同于逐接口重新执行；完整分类见 [coverage.json](evidence/2026-10-19-remaining-api-page-acceptance/coverage.json)。

本轮没有执行共享缓存/日志清空、强退其他用户、既有表创建/导入/同步、生成到本地文件系统或仿真流程。监控布局保存/删除等未执行项仍在矩阵中明列。
