# 用户管理与个人中心 HTTP 失败分类

日期：2026-10-16。本轮已完成，未提交或发布。

## 最终行为

| 场景 | HTTP | 现有错误码及反馈 |
| --- | --- | --- |
| 未认证、无效令牌、会话失效 | 401 | 保留认证异常及当前重新登录恢复入口。 |
| 用户数据范围不足 | 403 | 保留 30010 和原业务文案，进入普通错误反馈，不误报登录失效。 |
| 操作受保护的超级管理员 | 403 | 保留 30009 和原拒绝条件，进入普通错误反馈。 |
| 缺少接口权限 | 403 | 既有权限依赖继续返回 20004，行为不变。 |
| 个人中心旧密码错误 | 422 | 保留 30011；Problem Details 包含 `errors.field=oldPassword`，允许留在表单纠正。 |
| 个人中心新旧密码缺失、null 或空字符串 | 422 | 复用 Pydantic 请求校验及现有字段错误反馈，进入业务命令前拒绝。 |

两个授权失败改用现有 `PermissionException`，旧密码错误改用 `ValidationException`；不改变权限判定、认证实现或全局异常映射。CQRS、事务和审计继续保留原异常，由既有 Problem Details 处理器生成 HTTP 响应。前端生产 HTTP、业务码判断和反馈策略未改，未新增白名单；自动反馈入口失败一次提示一次，管理员重置密码 API 原有 manual 策略继续由调用方持有。

直接复用现有异常与错误出口，避免在前端修补后端状态，也无需全局重映射错误码。401 和 403 的职责依据 [RFC 9110](https://www.rfc-editor.org/rfc/rfc9110.html#name-401-unauthorized)；请求校验继续沿用 [FastAPI 的错误处理机制](https://fastapi.tiangolo.com/tutorial/handling-errors/)。错误分类属于业务责任，本轮没有修改 ZXUI 库实现。

## 密码入口的必要闭环

真实密码表单验证发现：`ResetUserModel` 继承的完整用户校验会在 CQRS 阶段要求未提供的账号，使合法密码请求先返回 500，无法到达旧密码比较。内部密码命令现采用同文件已有的部分校验模式，仅校验实际提供的用户字段，密码字符规则仍在模型构造时执行。

独立复核随后确认：放通该命令后，原本可空的旧密码会使服务跳过旧密码核验。因此个人中心专用 `ResetPasswordModel` 要求 oldPassword/newPassword 为必需、非空字符串，缺失/null/空字符串均在 HTTP 输入阶段拒绝。OpenAPI 和生成类型同步，仅这个 schema 变化，其他路径与模型保持一致。内部短信重置命令仍允许没有旧密码，短信校验流程未改，并有独立回归验证。

这两项是保证本轮“旧密码错误 422、纠正后可成功”成立所需的同一入口修复；没有扩展其他写接口契约。

真实业务验证 **25 组通过，0 个未处理拒绝**。使用生产 API、HTTP 和密码表单 SFC 的 setup/submit，直连 ZXUI 源码，通过真实 Axios XHR 访问本机 FastAPI、Docker MySQL 和已有 Redis：

- 仅本人数据范围的用户可以正常编辑自身；读取、编辑、改状态、删除、重置范围外用户均为 403/30010。
- 通过实际用户写接口尝试编辑、改状态、删除、重置超级管理员均为 403/30009；原管理员和目标用户数据不变，发起者会话仍有效。
- 无接口权限的正常登录用户得到 403/20004，仍可读取自己的个人资料。
- 个人中心六类缺失/null/空密码请求返回 422 字段错误；错误旧密码经生产密码表单返回 422/30011、oldPassword 明细，反馈一次、无重新登录提示，pending 释放。
- 失败后原密码仍能认证；同一生产表单纠正旧密码后提交成功，新密码可以登录。验证使用重新登录后签发的新会话，保留现有会话策略。
- 缺少认证、无效令牌、退出后重用已撤销会话三种真实请求均为 401，每次只提示一次重新登录；有效身份恢复后可继续读取。
- 错误保持实际 HTTP 状态、Problem Details、requestId、instance 和原始 config/cause 上下文。仅清理本轮创建的两名用户和一个角色，完整业务列表、字段和总数与管理员登录后采集的基线逐项相同。

以上是真实网络、数据库和提交决策验证。原生表单校验与视觉交互使用轻量替身，未做浏览器点击验收，未使用 computer use；短信发送及短信验证未执行真实业务调用，其内部命令语义由回归测试覆盖。不声称时间自然过期的令牌做了等待验证，本轮真实会话失效使用撤销会话。
