# 损坏 Excel 导入验收清单

- 解析边界：空文件、改名文本、截断 ZIP、非工作簿 ZIP、损坏工作簿 XML、损坏 XLS、缺失模板列；422 Problem Details，field=file，完整关闭上传句柄，不进入用户写入。
- 服务分类：读取/解析中的内部 RuntimeError 不伪装成用户输入错误；文件仍关闭。
- 正常契约：真实 XLSX 与 BIFF8 XLS 解析后继续返回批量结果，成功用户字段一致；现有逐行失败语义保留。
- 真实页面：下载模板，选择损坏 XLSX 并提交，检查一次明确中文错误、不显示系统繁忙；窗口保留且按钮恢复可操作。
- 真实页面恢复：移除损坏文件，选择有效模板，关闭“更新已有用户”，提交一次、展示结果，API 回读确认仅创建本轮账号；重复开关弹框状态重置。
- 探索：至少覆盖一个结构损坏的真实 XLSX，以及损坏 XLS，避免只测伪装文本。
- 视觉：1440x1000 和 1100x800 检查错误反馈、文件列表及确定/取消按钮可见；失败后截图，重试成功截图。
- 清理：只删除身份核验后的本轮账号、自己的认证/CSRF记录，关闭自建浏览器与 API contexts；保留本地服务。
- 证据不记录 token、Cookie 或 Authorization header；保留改动基线，不提交或推送。
