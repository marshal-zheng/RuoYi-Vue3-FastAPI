# 角色管理与双向授权浏览器验收

运行：实际源 std，ZXUI 源码直连；headed Chromium，1440×1000 和较小桌面 1024×768。

| ID | 用户可见行为/控件 | 交互与结果 | 视觉状态/证据 |
| --- | --- | --- | --- |
| R1 | 角色列表查询/重置/分页/刷新 | 提交条件、页码重置、返回恢复 | 初始、筛选、有数据列表 |
| R2 | 新增/编辑/状态/删除 | 校验、保存、状态完整周期、管理可读 | 表单错误、编辑树、状态行、确认框 |
| R3 | 数据范围 | 模式切换、树选择、保存与重开 | 数据范围抽屉 |
| A1 | 角色分配用户/选择弹框 | 搜索、分页、跨页勾选/取消、保存与重开 | 弹框、选中反馈、分配后列表 |
| A2 | 单条/批量撤销 | 确认、取消与完成、返回 | 确认框、撤销后列表 |
| U1 | 用户授权角色 | 完整关联、跨页保留草稿、取消/保存、空数组 | 勾选、保存后重开、清空 |
| U2 | 用户/角色列表返回 | 保留已提交筛选页码、关闭/返回 | 返回后的页面状态 |
| X1 | 快速搜索、关闭重开 | 过时请求不污染新会话、选择重置 | 探索序列稳定性 |
| X2 | 网络失败/恢复与键盘 | 失败可见、重试、Tab/Enter/Escape | 错误、恢复、焦点/遮挡 |
| V1 | 1440×1000 与 1024×768 | 主要控件、表格、底部按钮可见可用 | 截图+元素边界；无裁切、重叠、错层、溢出 |

所有业务写入只用于本轮命名的临时用户/角色；完成后删除并核对。功能签收使用实际点击/键盘，不用 evaluate 改应用状态替代交互。
