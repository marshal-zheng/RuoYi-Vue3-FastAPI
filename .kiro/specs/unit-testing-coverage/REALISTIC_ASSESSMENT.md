## 🔍 问题根源分析

### 1. 测试与代码不同步
许多测试是基于假设的API创建的，而不是基于实际代码：
- `PwdUtil.hash_password` 不存在 → 实际可能是其他方法名
- `UserService.add_user` 不存在 → 实际方法名不同
- `MenuService.delete_menu` 不存在 → 实际方法名不同

### 2. 导入问题
- `UserDO` 无法从 `user_do.py` 导入
- 实际的类名可能是 `User` 或其他名称

### 3. 覆盖率工具问题
- 前端 `@vitest/coverage-v8` 版本不兼容
- 无法生成准确的覆盖率报告


#### 第2步: 创建简单的集成测试 (4-5小时)

2. `tests/integration/test_protocol_api.py` - 协议API集成测试
3. `tests/integration/test_simulation_api.py` - 仿真API集成测试
4. `tests/integration/test_user_api.py` - 用户API集成测试

每个文件包含：
- 基本CRUD操作测试
- 使用TestClient
- 不Mock service层
- 测试实际数据库操作

#### 第3步: 修复前端覆盖率工具 (1-2小时)
```bash
# 尝试降级vitest
yarn add -D vitest@2.1.8 @vitest/coverage-v8@2.1.8

# 或者使用c8
yarn add -D c8
```

#### 第4步: 运行并验证 (1-2小时)
```bash
# 后端
pytest tests/unit/services/test_project_service.py \
       tests/unit/services/test_protocol_service.py \
       tests/integration/ \
       --cov=module_admin --cov-report=html

# 前端
yarn test --coverage
```
