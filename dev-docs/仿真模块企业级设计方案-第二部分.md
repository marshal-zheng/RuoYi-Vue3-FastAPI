## 6. 仿真业务逻辑设计

### 6.1 仿真生命周期管理

仿真生命周期管理是整个仿真系统的核心控制逻辑,负责管理仿真会话从创建到销毁的完整过程。

#### 6.1.1 会话创建流程

**业务流程图**:

```
用户请求 → 参数验证 → 静态校验 → 会话初始化 → 状态持久化 → 返回会话ID
```

**详细步骤**:

1. **接收创建请求**
   - 接口: `POST /api/simulation/session`
   - 必填参数: `project_id`, `version_id`, `topology_config`, `simulation_params`
   - 权限验证: 需要仿真模块的创建权限

2. **参数验证**
   - 验证项目和版本ID的有效性
   - 验证拓扑配置完整性(节点、连接、协议配置)
   - 验证仿真参数合理性(速度倍率范围、时长限制)

3. **静态校验**
   - **拓扑验证**: 检测环路、多连、孤立节点
   - **协议一致性**: 验证连接两端协议是否匹配
   - **带宽预估**: 根据消息周期预计算带宽是否溢出

4. **会话初始化**
   - 生成唯一会话ID (UUID v4)
   - 创建SimPy `RealtimeEnvironment` 实例
   - 根据拓扑配置初始化协议模型插件
   - 分配必要的计算资源和内存空间

5. **状态持久化**
   - 数据库: 保存会话元数据(`simulation_sessions`表)
   - Redis: 初始化会话缓存(key: `session:{session_id}`)
   - 日志: 记录创建操作审计日志

**关键设计点**:

```python
# 服务层伪代码示例
class SimulationSessionService:
    async def create_session(self, params) -> Session:
        # 验证 → 校验 → 初始化 → 持久化
        await self._validate(params)
        await self._static_check(params.topology)
        session = await self._init_session(params)
        await self._persist(session)
        return session
```

#### 6.1.2 启动/暂停/恢复/停止状态机

**状态转换图**:

```
CREATED -> START -> RUNNING
                    ↓ PAUSE
                 PAUSED
                    ↓ RESUME
                 RUNNING
                    ↓ STOP
                 STOPPED
```

**状态说明**:

| 状态 | 描述 | 允许操作 |
|------|------|----------|
| CREATED | 会话已创建,未启动 | start, stop |
| RUNNING | 仿真正在运行 | pause, stop, speed_adjust |
| PAUSED | 仿真已暂停 | resume, stop |
| STOPPED | 仿真已停止(终态) | 无 |

**状态转换逻辑**:

| 操作 | 前置状态 | 目标状态 | 核心动作 |
|------|---------|---------|----------|
| **START** | CREATED | RUNNING | 启动SimulationRunner线程 + 建立WebSocket连接 + 开始数据推送 |
| **PAUSE** | RUNNING | PAUSED | 暂停SimPy环境时间推进 + 保留状态快照 + 停止数据推送 |
| **RESUME** | PAUSED | RUNNING | 恢复SimPy时间推进 + 从快照继续执行 + 恢复数据推送 |
| **STOP** | RUNNING/PAUSED | STOPPED | 停止SimulationRunner + 归档数据 + 清理资源 + 关闭连接 |

**设计要点**:

1. **START (启动)**
   - 在独立线程中启动 `SimulationRunner`,避免阻塞FastAPI异步循环
   - WebSocket连接建立后立即推送初始状态
   - 记录启动时间戳,用于计算仿真进度

2. **PAUSE (暂停)**
   - 通过命令队列发送暂停指令到SimulationRunner
   - 保存当前仿真时间和所有协议状态到快照
   - 停止数据推送但保持WebSocket连接(用于接收控制命令)

3. **RESUME (恢复)**
   - 从快照恢复仿真状态,确保无缝续传
   - 补发暂停期间丢失的心跳,防止前端误判断线
   - 记录暂停时长,用于统计实际运行时间

4. **STOP (停止)**
   - 优雅停止SimulationRunner,等待当前事件完成
   - 归档仿真数据到MySQL,清理Redis临时缓存
   - 生成会话摘要报告(报文总数、带宽峰值、告警统计)

#### 6.1.3 速度调节机制

仿真速度调节允许用户动态改变仿真时间与真实时间的比例关系。

**速度倍率范围**:
- **最小**: 0.1x (慢速仿真,用于细粒度观察)
- **默认**: 1.0x (实时仿真)
- **最大**: 10.0x (快速仿真,用于长时间场景测试)

**调节策略**:

1. **动态调速**
   - 运行时实时调节,无需重启仿真
   - 通过修改 `RealtimeEnvironment.factor` 实现
   - 平滑过渡,避免仿真时间跳变

2. **性能自适应**
   - 持续监控CPU负载和仿真执行延迟
   - 当实际执行落后仿真时钟时,自动降低速度倍率
   - 防止"时间溢出"(仿真时间超前实际计算能力)导致结果失真

3. **协议约束**
   - 验证协议时序要求(如MIL-STD-1553B的2-12μs响应时间)
   - 高速模式下检查时序可行性,防止违反协议规范
   - 必要时对最大速度进行限制并提示用户

**实现要点**:

- 速度调节命令通过 `command_queue` 异步发送到SimulationRunner线程
- 前端通过WebSocket接收速度变更通知,同步更新UI显示
- 速度调节记录到操作日志,用于审计和问题追溯

#### 6.1.4 数据清理策略

**清理场景**:

1. **会话停止后清理**
   - 清理SimPy环境对象
   - 释放协议模型内存
   - 清理Redis缓存
   - 保留数据库记录(用于历史查询)

2. **会话超时清理**
   - 检测长时间无活动的会话
   - 自动停止并清理资源
   - 超时时间:30分钟无操作

3. **数据归档**
   - 仿真数据批量转储到MySQL
   - 压缩历史报文数据
   - 清理过期数据(默认保留30天)

**清理流程**:

```
停止Runner线程 → 清理SimPy环境 → 删除Redis缓存 → 归档数据 → 关闭数据库连接 → 记录日志
```

**设计要点**:

- 使用 `try-finally` 确保资源清理即使在异常情况下也能执行
- 归档数据采用异步批量写入,避免阻塞主流程
- Redis缓存使用通配符删除: `DEL session:{session_id}:*`
- 数据库保留会话记录和告警日志,仅清理临时数据

### 6.2 协议仿真逻辑

#### 6.2.1 MIL-STD-1553B协议仿真

**协议特性**:
- **总线类型**: 时分复用(TDM)主从架构
- **传输速率**: 1 Mbps
- **字长**: 20位(16位数据 + 3位同步 + 1位奇偶校验)
- **响应时间**: BC发送命令后,RT必须在2-12μs内响应

**仿真组件**:

1. **总线控制器(BC)**
   - 发起总线通信
   - 调度RT通信时隙
   - 执行BC-RT、RT-RT通信

2. **远程终端(RT)**
   - 响应BC命令
   - 接收/发送数据
   - 状态字返回

3. **总线监视器(BM)**
   - 被动监听总线流量
   - 记录所有通信

**仿真逻辑**:

```python
class MIL1553BProtocolModel(BaseProtocolModel):
    WORD_TIME = 20e-6  # 20μs per word
    RESPONSE_TIME = 2e-6  # 2μs min response
    
    def __init__(self, env: RealtimeEnvironment, config: BusConfig):
        super().__init__(env, config)
        self.bc_node = config.bc_node
        self.rt_nodes = config.rt_nodes
        self.message_schedule = config.message_schedule
    
    async def simulate(self):
        """BC主循环"""
        while True:
            for msg_config in self.message_schedule:
                yield self.env.timeout(msg_config.period)
                
                # BC-RT 写命令
                if msg_config.direction == "BC_TO_RT":
                    yield from self._bc_to_rt_transfer(msg_config)
                
                # BC-RT 读命令
                elif msg_config.direction == "RT_TO_BC":
                    yield from self._rt_to_bc_transfer(msg_config)
                
                # RT-RT 传输
                elif msg_config.direction == "RT_TO_RT":
                    yield from self._rt_to_rt_transfer(msg_config)
    
    def _bc_to_rt_transfer(self, msg_config: MessageConfig):
        """BC向RT发送数据"""
        # 1. BC发送命令字
        cmd_word = self._build_command_word(
            rt_addr=msg_config.rt_addr,
            subaddr=msg_config.subaddr,
            word_count=len(msg_config.data),
            tr_bit=0  # 0=接收
        )
        yield self.env.timeout(self.WORD_TIME)
        self._record_message("CMD", cmd_word)
        
        # 2. BC发送数据字
        for data_word in msg_config.data:
            yield self.env.timeout(self.WORD_TIME)
            self._record_message("DATA", data_word)
        
        # 3. 等待RT响应
        yield self.env.timeout(self.RESPONSE_TIME)
        
        # 4. RT返回状态字
        status_word = self._build_status_word(msg_config.rt_addr)
        yield self.env.timeout(self.WORD_TIME)
        self._record_message("STATUS", status_word)
        
        # 5. 带宽统计
        total_words = 1 + len(msg_config.data) + 1  # CMD + DATA + STATUS
        bandwidth = total_words * 20 / msg_config.period  # bits/sec
        self._update_bandwidth(bandwidth)
    
    def _build_command_word(self, rt_addr, subaddr, word_count, tr_bit):
        """构建命令字(20位)"""
        word = (
            (0b111 << 17) |           # 同步头(3位)
            (rt_addr << 12) |         # RT地址(5位)
            (tr_bit << 11) |          # T/R位(1位)
            (subaddr << 6) |          # 子地址(5位)
            (word_count << 1)         # 数据字数(5位)
        )
        parity = self._calculate_parity(word)
        return word | parity
```

**总线仲裁**:
- MIL-STD-1553B采用BC集中控制,无需仲裁
- BC通过消息调度表控制总线访问顺序
- 冲突检测:检查是否存在时隙重叠

#### 6.2.2 CAN总线仿真

**协议特性**:
- **总线类型**: 多主竞争式总线
- **传输速率**: 125 Kbps - 1 Mbps
- **仲裁机制**: 基于标识符优先级(ID越小优先级越高)
- **帧格式**: 标准帧(11位ID)、扩展帧(29位ID)

**仿真组件**:

1. **CAN节点**
   - 发送CAN帧
   - 接收匹配ID的帧
   - 执行位仲裁

2. **CAN总线**
   - 模拟物理总线(线与逻辑)
   - 仲裁裁决
   - 广播帧到所有节点

**仲裁逻辑**:

```python
class CANBusModel(BaseProtocolModel):
    def __init__(self, env: RealtimeEnvironment, config: BusConfig):
        super().__init__(env, config)
        self.nodes = [CANNode(env, node_cfg) for node_cfg in config.nodes]
        self.bus = CANBus(env)
        self.baudrate = config.baudrate
    
    def _arbitrate(self, competing_frames: List[CANFrame]) -> CANFrame:
        """位仲裁:返回优先级最高(ID最小)的帧"""
        if not competing_frames:
            return None
        
        # 按ID排序,ID最小者获胜
        competing_frames.sort(key=lambda f: f.can_id)
        winner = competing_frames[0]
        
        # 检测冲突
        if len(competing_frames) > 1:
            self._record_collision(competing_frames)
        
        return winner
    
    async def simulate_frame_transmission(self, frame: CANFrame):
        """仿真帧传输"""
        # 1. 仲裁阶段
        competing = self._get_competing_frames()
        winner = self._arbitrate(competing + [frame])
        
        if winner != frame:
            # 仲裁失败,稍后重试
            yield self.env.timeout(random.uniform(0, 0.001))
            yield from self.simulate_frame_transmission(frame)
            return
        
        # 2. 传输帧
        bit_time = 1 / self.baudrate
        frame_bits = self._calculate_frame_bits(frame)
        
        for bit_idx in range(frame_bits):
            yield self.env.timeout(bit_time)
            if bit_idx < frame.can_id.bit_length():
                # 仲裁阶段:监听总线
                bus_value = self.bus.read_bit()
                if bus_value != frame.get_bit(bit_idx):
                    # 仲裁失败
                    return
        
        # 3. 广播到所有节点
        for node in self.nodes:
            if node.accepts_id(frame.can_id):
                node.receive_frame(frame)
        
        # 4. 带宽统计
        transmission_time = frame_bits * bit_time
        self._update_bandwidth(frame_bits / transmission_time)
```

**帧格式**:

| 字段 | 标准帧 | 扩展帧 | 描述 |
|------|--------|--------|------|
| SOF | 1位 | 1位 | 帧起始 |
| ID | 11位 | 29位 | 标识符(仲裁字段) |
| RTR | 1位 | 1位 | 远程传输请求 |
| Control | 6位 | 6位 | 控制字段(含DLC) |
| Data | 0-64位 | 0-64位 | 数据字段 |
| CRC | 16位 | 16位 | 循环冗余校验 |
| ACK | 2位 | 2位 | 应答 |
| EOF | 7位 | 7位 | 帧结束 |

#### 6.2.3 RS422/RS485串口仿真

**协议特性**:
- **物理层**: 差分信号,抗干扰能力强
- **传输速率**: 9600 bps - 115200 bps
- **通信模式**: 
  - RS422: 全双工,点对点
  - RS485: 半双工,多点总线

**仿真逻辑**:

```python
class RS485BusModel(BaseProtocolModel):
    def __init__(self, env: RealtimeEnvironment, config: BusConfig):
        super().__init__(env, config)
        self.baudrate = config.baudrate
        self.nodes = config.nodes
        self.bus_busy = False
    
    async def send_frame(self, sender: str, data: bytes):
        """发送UART帧"""
        # 1. 检查总线空闲(RS485半双工)
        while self.bus_busy:
            yield self.env.timeout(0.001)
        
        self.bus_busy = True
        
        # 2. 逐字节传输
        bit_time = 1 / self.baudrate
        for byte_val in data:
            # 起始位(0)
            yield self.env.timeout(bit_time)
            
            # 数据位(8位)
            for bit_idx in range(8):
                yield self.env.timeout(bit_time)
            
            # 奇偶校验位(可选)
            yield self.env.timeout(bit_time)
            
            # 停止位(1或2位)
            yield self.env.timeout(bit_time)
        
        self.bus_busy = False
        
        # 3. 广播到其他节点
        for node in self.nodes:
            if node.name != sender:
                node.receive_data(data)
        
        # 4. 带宽统计
        frame_bits = len(data) * 10  # 1起始 + 8数据 + 1停止
        transmission_time = frame_bits * bit_time
        self._update_bandwidth(frame_bits / transmission_time)
```

#### 6.2.4 LAN以太网仿真

**协议特性**:
- **传输速率**: 100 Mbps / 1 Gbps
- **帧格式**: Ethernet II
- **传输模式**: UDP(无连接)、TCP(面向连接)

**仿真逻辑**:

```python
class EthernetBusModel(BaseProtocolModel):
    def __init__(self, env: RealtimeEnvironment, config: BusConfig):
        super().__init__(env, config)
        self.bandwidth = config.bandwidth  # 100Mbps or 1Gbps
        self.switches = {}  # MAC地址表
    
    async def send_udp_packet(
        self,
        src_ip: str,
        dst_ip: str,
        payload: bytes
    ):
        """发送UDP数据包"""
        # 1. 构建以太网帧
        eth_frame = self._build_ethernet_frame(
            src_mac=self._get_mac(src_ip),
            dst_mac=self._get_mac(dst_ip),
            ethertype=0x0800  # IPv4
        )
        
        # 2. 构建IP数据包
        ip_packet = self._build_ip_packet(
            src_ip=src_ip,
            dst_ip=dst_ip,
            protocol=17  # UDP
        )
        
        # 3. 构建UDP数据报
        udp_datagram = self._build_udp_datagram(
            src_port=self.config.src_port,
            dst_port=self.config.dst_port,
            data=payload
        )
        
        # 4. 计算传输时间
        total_bytes = len(eth_frame) + len(ip_packet) + len(udp_datagram)
        transmission_time = (total_bytes * 8) / self.bandwidth
        
        yield self.env.timeout(transmission_time)
        
        # 5. 交付目标节点
        dst_node = self._find_node_by_ip(dst_ip)
        if dst_node:
            dst_node.receive_packet(udp_datagram)
        
        # 6. 带宽统计
        self._update_bandwidth(total_bytes * 8 / transmission_time)
```

### 6.3 带宽计算与监控

#### 6.3.1 协议带宽计算公式

**通用公式**:

```
带宽(bps) = 数据量(bits) / 时间间隔(seconds)
```

**协议特定公式**:

1. **MIL-STD-1553B**
   ```
   每帧带宽 = (命令字 + 数据字数 * 16 + 状态字) * 20位 / 消息周期
   总线带宽 = Σ(各消息带宽)
   ```

2. **CAN总线**
   ```
   标准帧位数 = 1(SOF) + 11(ID) + 6(Control) + 数据长度*8 + 16(CRC) + 10(ACK+EOF)
              = 44 + 数据长度*8
   帧带宽 = 帧位数 / 传输周期
   ```

3. **RS422/RS485**
   ```
   字节位数 = 1(起始) + 8(数据) + 1(校验) + 1(停止) = 11位
   带宽 = 字节数 * 11 / 传输时间
   ```

4. **Ethernet**
   ```
   以太网帧 = 14(帧头) + IP头(20) + UDP头(8) + 数据负载
   带宽 = 总字节数 * 8 / 传输时间
   ```

#### 6.3.2 实时带宽统计

**统计策略**:

1. **滑动窗口统计**
   - 窗口大小:1秒(可配置)
   - 使用 `collections.deque` 存储时间戳和数据量
   - 实时计算窗口内的平均带宽

```python
from collections import deque
from datetime import datetime, timedelta

class BandwidthMonitor:
    def __init__(self, window_size: float = 1.0):
        self.window_size = window_size  # 秒
        self.samples = deque()  # (timestamp, bits)
    
    def record_transmission(self, bits: int):
        """记录一次传输"""
        now = datetime.now()
        self.samples.append((now, bits))
        
        # 清理过期样本
        cutoff = now - timedelta(seconds=self.window_size)
        while self.samples and self.samples[0][0] < cutoff:
            self.samples.popleft()
    
    def get_current_bandwidth(self) -> float:
        """获取当前带宽(bps)"""
        if not self.samples:
            return 0.0
        
        total_bits = sum(bits for _, bits in self.samples)
        time_span = (
            self.samples[-1][0] - self.samples[0][0]
        ).total_seconds()
        
        if time_span == 0:
            return 0.0
        
        return total_bits / time_span
```

2. **分层统计**
   - **节点级**: 每个节点的发送/接收带宽
   - **总线级**: 整条总线的总带宽
   - **协议级**: 按协议类型分类统计

```python
class HierarchicalBandwidthMonitor:
    def __init__(self):
        self.node_monitors = {}      # node_id -> BandwidthMonitor
        self.bus_monitors = {}       # bus_id -> BandwidthMonitor
        self.protocol_monitors = {}  # protocol -> BandwidthMonitor
    
    def record_transmission(
        self,
        node_id: str,
        bus_id: str,
        protocol: str,
        bits: int
    ):
        # 节点级
        if node_id not in self.node_monitors:
            self.node_monitors[node_id] = BandwidthMonitor()
        self.node_monitors[node_id].record_transmission(bits)
        
        # 总线级
        if bus_id not in self.bus_monitors:
            self.bus_monitors[bus_id] = BandwidthMonitor()
        self.bus_monitors[bus_id].record_transmission(bits)
        
        # 协议级
        if protocol not in self.protocol_monitors:
            self.protocol_monitors[protocol] = BandwidthMonitor()
        self.protocol_monitors[protocol].record_transmission(bits)
```

#### 6.3.4 历史数据聚合

**聚合策略**:

```python
class BandwidthAggregator:
    def __init__(self):
        self.realtime_buffer = deque(maxlen=100)   # 10秒 * 10Hz
        self.short_term_buffer = deque(maxlen=300) # 5分钟

    async def aggregate_loop(self):
        """后台聚合任务"""
```

```python
class TopologyValidator:
    async def validate(self, topology: TopologyConfig) -> ValidationResult:
        errors = []
        warnings = []

        for node in topology.nodes:
            if not node.node_id:

        # 检查连接配置
        for conn in topology.connections:

            dst_node = topology.get_node(conn.target)

            if src_node.protocol != dst_node.protocol:
                warnings.append(
                    f"Protocol mismatch: {src_node.name}({src_node.protocol}) "
                    f"-> {dst_node.name}({dst_node.protocol})"
                )
        
        return ValidationResult(
            is_valid=len(errors) == 0,
            errors=errors,
            warnings=warnings
        )
```

**2. 环路检测**

使用深度优先搜索(DFS)检测拓扑图中的环路。

```python
class LoopDetector:
    def detect_loops(self, topology: TopologyConfig) -> List[Loop]:
        graph = self._build_graph(topology)
        loops = []
        visited = set()
        rec_stack = set()
        
        def dfs(node, path):
            visited.add(node)
            rec_stack.add(node)
            path.append(node)
            
            for neighbor in graph.get(node, []):
                if neighbor not in visited:
                    dfs(neighbor, path)
                elif neighbor in rec_stack:
                    # 发现环路
                    loop_start = path.index(neighbor)
                    loop = path[loop_start:]
                    loops.append(Loop(nodes=loop))
            
            path.pop()
            rec_stack.remove(node)
        
        for node in graph:
            if node not in visited:
                dfs(node, [])
        
        return loops
```

```python
class CollisionDetector:
    def __init__(self):
        self.active_transmissions = {}  # bus_id -> List[Transmission]
    
    def check_collision(
        self,
        bus_id: str,
        transmission: Transmission
    ) -> Optional[Alarm]:
        # 获取当前总线上的活跃传输
        active = self.active_transmissions.get(bus_id, [])
        
        # 检查时间重叠
        collisions = []
        for tx in active:
            if self._time_overlap(tx, transmission):
                collisions.append(tx)
        
        if collisions:
            return Alarm(
                type=AlarmType.COLLISION,
                level=AlarmLevel.CRITICAL,
                message=f"Collision detected on bus {bus_id}",
                details={
                    "bus_id": bus_id,
                    "colliding_nodes": [tx.node_id for tx in collisions],
                    "timestamp": transmission.start_time
                }
            )
        
        # 记录当前传输
        active.append(transmission)
        self.active_transmissions[bus_id] = active
        
        return None
    
    def _time_overlap(self, tx1: Transmission, tx2: Transmission) -> bool:
        return not (
            tx1.end_time <= tx2.start_time or
            tx2.end_time <= tx1.start_time
        )
```

**3. 丢包检测**

```python
class PacketLossDetector:
    def __init__(self):
        self.expected_seq = {}  # node_id -> expected_sequence_number
    
    def check_packet_loss(
        self,
        node_id: str,
        packet: Packet
    ) -> Optional[Alarm]:
        expected = self.expected_seq.get(node_id, 0)
        
        if packet.sequence_number != expected:
            lost_count = packet.sequence_number - expected
            
            self.expected_seq[node_id] = packet.sequence_number + 1
            
            return Alarm(
                type=AlarmType.PACKET_LOSS,
                level=AlarmLevel.CRITICAL,
                message=f"Packet loss detected on node {node_id}",
                details={
                    "node_id": node_id,
                    "expected_seq": expected,
                    "actual_seq": packet.sequence_number,
                    "lost_count": lost_count
                }
            )
        
        self.expected_seq[node_id] = expected + 1
        return None
```

#### 6.5.2 事件触发时机与条件

**触发时机**:

2. **条件触发**

```python
class FaultInjector:
    def __init__(self, env: RealtimeEnvironment):
        self.env = env
        self.active_faults = []
    
    async def schedule_fault(self, fault: FaultConfig):
        """调度故障注入"""
        # 等待到触发时间
        yield self.env.timeout(fault.trigger_time)
        
        # 激活故障
        await self._activate_fault(fault)
        
        # 如果有持续时间,设置自动恢复
        if fault.duration:
            yield self.env.timeout(fault.duration)
            await self._deactivate_fault(fault)
    
    async def _activate_fault(self, fault: FaultConfig):
        if fault.fault_type == "packet_loss":
            # 修改目标节点的发送逻辑
            node = self._get_node(fault.target_node)
            node.set_packet_loss_rate(
                fault.parameters["loss_rate"]
            )
        
        elif fault.fault_type == "delay":
            node = self._get_node(fault.target_node)
            node.add_transmission_delay(
                fault.parameters["delay_ms"] / 1000
            )
        
        elif fault.fault_type == "disconnect":
            node = self._get_node(fault.target_node)
            node.disconnect()
        
        self.active_faults.append(fault)
        
        # 记录事件
        await self._log_fault_event("activated", fault)
```

## 7. 仿真接口设计

### 7.1 接口设计原则

#### 7.1.1 RESTful规范

**原则**:

1. **资源导向**
   - URL表示资源,使用名词而非动词
   - 示例: `/api/simulation/session` (资源) 而非 `/api/createSession` (动作)

2. **HTTP方法语义**
   | 方法 | 语义 | 幂等性 |
   |------|------|--------|
   | GET | 获取资源 | 是 |
   | POST | 创建资源 | 否 |
   | PUT | 完整更新资源 | 是 |
   | PATCH | 部分更新资源 | 否 |
   | DELETE | 删除资源 | 是 |

3. **状态码规范**
   | 状态码 | 含义 | 使用场景 |
   |-------|------|----------|
   | 200 | 成功 | GET/PUT/PATCH成功 |
   | 201 | 已创建 | POST成功创建资源 |
   | 204 | 无内容 | DELETE成功 |
   | 400 | 请求错误 | 参数验证失败 |
   | 401 | 未授权 | JWT过期或无效 |
   | 403 | 禁止访问 | 无权限操作 |
   | 404 | 未找到 | 资源不存在 |
   | 500 | 服务器错误 | 内部异常 |

4. **统一响应格式**
   ```json
   {
     "code": 200,
     "message": "Success",
     "data": { ... },
     "timestamp": "2025-12-12T10:30:00Z"
   }
   ```

#### 7.1.2 WebSocket协议

**原则**:

1. **连接管理**
   - 每个仿真会话对应一个WebSocket连接
   - 连接URL: `/ws/simulation/{session_id}`
   - 支持JWT认证(通过查询参数或子协议)

2. **消息格式**
   ```json
   {
     "type": "message|bandwidth|alarm|status",
     "timestamp": 1702345678.123,
     "data": { ... }
   }
   ```

3. **心跳机制**
   - 客户端每30秒发送心跳: `{"type": "ping"}`
   - 服务端响应: `{"type": "pong"}`
   - 超过60秒无心跳则断开连接

4. **断线重连**
   - 客户端检测断线后自动重连
   - 重连时携带上次接收的序列号,服务端补发丢失数据

### 7.2 接口安全性

#### 7.2.1 JWT认证

**认证流程**:

1. 用户登录获取JWT Token
2. 在请求头中携带Token: `Authorization: Bearer <token>`
3. 后端验证Token有效性(签名、过期时间)
4. 提取用户信息,校验权限

**实现代码**:

```python
from fastapi import Depends, HTTPException, status
from fastapi.security import HTTPBearer, HTTPAuthorizationCredentials
from jose import JWTError, jwt

security = HTTPBearer()

async def get_current_user(
    credentials: HTTPAuthorizationCredentials = Depends(security)
) -> User:
    token = credentials.credentials
    
    if not verify_token(token):
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Invalid authentication credentials"
        )
    
    payload = jwt.decode(
        token,
        settings.SECRET_KEY,
        algorithms=[settings.ALGORITHM]
    )
    
    user_id = payload.get("sub")
    if user_id is None:
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Invalid token payload"
        )
    
    user = await user_service.get_user_by_id(user_id)
    if user is None:
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="User not found"
        )
    
    return user
```

#### 7.2.2 会话隔离

**隔离策略**:

1. **数据隔离**
   - 每个会话的数据存储在独立的Redis key下
   - 数据库查询强制添加 `session_id` 过滤条件

2. **权限校验**
   - 用户只能操作自己创建的会话
   - 管理员可以查看所有会话,但不能操作

```python
async def check_session_permission(
    session_id: str,
    user: User,
    require_owner: bool = True
) -> SimulationSession:
    session = await simulation_service.get_session(session_id)
    
    if session is None:
        raise HTTPException(status_code=404, detail="Session not found")
    
    # 管理员拥有查看权限
    if user.role == "admin":
        return session
    
    # 非管理员只能操作自己的会话
    if require_owner and session.created_by != user.id:
        raise HTTPException(
            status_code=403,
            detail="No permission to access this session"
        )
    
    return session
```

```python
@app.websocket("/ws/simulation/{session_id}")
async def websocket_endpoint(
    websocket: WebSocket,
    session_id: str,
    token: str = Query(...)
):
    # 验证JWT Token
    user = await verify_websocket_token(token)
    if not user:
        await websocket.close(code=1008, reason="Unauthorized")
        return

    await websocket.accept()

    await connection_manager.connect(session_id, websocket)
    
    await websocket.send_json({
        "type": "connected",
        "message": "WebSocket connection established",
        "session_id": session_id
    })
    
    # 启动数据推送任务
    push_task = asyncio.create_task(
        push_simulation_data(session_id, websocket)
    )
    
    # 处理客户端消息
    while True:
        data = await websocket.receive_json()
        
        if data["type"] == "ping":
            await websocket.send_json({"type": "pong"})
        
        elif data["type"] == "subscribe":
            # 订阅特定数据类型
            await handle_subscription(session_id, websocket, data)
    
    # 清理

    await connection_manager.disconnect(session_id, websocket)
```

**心跳机制**:

```python
class HeartbeatManager:
    HEARTBEAT_INTERVAL = 30  # 秒
    TIMEOUT = 60  # 秒
    
    def __init__(self):
        self.last_heartbeat = {}  # session_id -> timestamp
    
    async def start_heartbeat_check(self, session_id: str, websocket: WebSocket):
        """启动心跳检测"""
        while True:
            await asyncio.sleep(self.HEARTBEAT_INTERVAL)
            
            # 检查是否超时
            last = self.last_heartbeat.get(session_id, 0)
            if time.time() - last > self.TIMEOUT:
                logger.warning(f"Session {session_id} heartbeat timeout")
                await websocket.close(code=1000, reason="Heartbeat timeout")
                break
    
    def update_heartbeat(self, session_id: str):
        """更新心跳时间"""
        self.last_heartbeat[session_id] = time.time()
```

**断线重连**:

```javascript
// 前端断线重连逻辑
class SimulationWebSocket {
  constructor(sessionId, token) {
    this.sessionId = sessionId;
    this.token = token;
    this.reconnectAttempts = 0;
    this.maxReconnectAttempts = 5;
    this.reconnectDelay = 3000; // 3秒
    this.lastSequenceNumber = 0;
    
    this.connect();
  }
  
  connect() {
    const url = `ws://localhost:8000/ws/simulation/${this.sessionId}?token=${this.token}&seq=${this.lastSequenceNumber}`;
    this.ws = new WebSocket(url);
    
    this.ws.onopen = () => {
      console.log('WebSocket connected');
      this.reconnectAttempts = 0;
      this.startHeartbeat();
    };
    
    this.ws.onmessage = (event) => {
      const data = JSON.parse(event.data);
      this.lastSequenceNumber = data.sequence || this.lastSequenceNumber;
      this.handleMessage(data);
    };
    
    this.ws.onerror = (error) => {
      console.error('WebSocket error:', error);
    };
    
    this.ws.onclose = () => {
      console.log('WebSocket disconnected');
      this.stopHeartbeat();
      this.attemptReconnect();
    };
  }
  
  attemptReconnect() {
    if (this.reconnectAttempts >= this.maxReconnectAttempts) {
      console.error('Max reconnect attempts reached');
      return;
    }
    
    this.reconnectAttempts++;
    const delay = this.reconnectDelay * Math.pow(2, this.reconnectAttempts - 1);
    
    console.log(`Reconnecting in ${delay}ms (attempt ${this.reconnectAttempts})`);
    
    setTimeout(() => {
      this.connect();
    }, delay);
  }
  
  startHeartbeat() {
    this.heartbeatInterval = setInterval(() => {
      if (this.ws.readyState === WebSocket.OPEN) {
        this.ws.send(JSON.stringify({ type: 'ping' }));
      }
    }, 30000); // 30秒
  }
  
  stopHeartbeat() {
    if (this.heartbeatInterval) {
      clearInterval(this.heartbeatInterval);
    }
  }
  
  handleMessage(data) {
    // 根据消息类型分发处理
    switch (data.type) {
      case 'message':
        this.onMessageData(data.data);
        break;
      case 'bandwidth':
        this.onBandwidthData(data.data);
        break;
      case 'alarm':
        this.onAlarmData(data.data);
        break;
      case 'status':
        this.onStatusUpdate(data.data);
        break;
      case 'pong':
        // 心跳响应
        break;
    }
  }
}
```
