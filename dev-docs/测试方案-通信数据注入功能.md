**测试场景：**配置不完整时，系统应该使用默认值

**预期增强：**
```python
# 应该增加payload字段
message = {
    # ... 现有字段 ...
    'payload': self._generate_payload(port_config),  # 新增
    'payload_hex': payload.hex(),  # 十六进制表示
}

def _generate_payload(self, port_config: dict) -> bytes:
    """根据message_config.fields生成实际报文内容"""
    message_config = port_config.get('message_config', {})
    fields = message_config.get('fields', [])
    
    payload = bytearray()
    for field in fields:
        # 根据字段定义生成数据
        value = self._generate_field_value(field)
        payload.extend(value)
    
    return bytes(payload)
```

## 九、问题排查指南

### 问题1：报文未生成
**检查项：**
1. 拓扑中是否有边连接
2. 端口配置中params是否包含frequency
3. 后端仿真引擎是否正常启动
4. WebSocket是否连接成功

**日志位置：**
- 后端：`ruoyi-fastapi-backend/logs/`
- 浏览器控制台：Network -> WS标签

### 问题2：报文数据不正确
**检查项：**
1. message_config是否正确保存
2. 查看数据库中的JSON结构
3. 检查后端解析逻辑

### 问题3：自动填充不工作
**检查项：**
1. 拓扑边的source/target是否正确
2. 设备名称是否为空
3. deviceMode参数是否正确
