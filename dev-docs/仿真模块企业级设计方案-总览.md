## 文档说明

本设计方案文档是针对多总线混合设计仿真管理系统中**仿真模块**的完整设计说明,覆盖仿真引擎架构、前后端实现、协议模拟、实时通信、性能优化、测试验证等核心内容。

仿真模块是系统的核心功能,负责对多总线拓扑进行离散事件仿真、实时报文监控、带宽分析和告警检测。本文档按照企业级系统设计规范编写,为仿真功能的开发、测试和维护提供全面指导。

由于文档内容详实,为便于阅读和维护,文档分为三个部分:

## 核心内容概览

### 技术架构亮点

**后端核心技术**:
- **FastAPI 0.115.8**: 高性能异步Web框架,支持WebSocket
- **SimPy 4.1+**: 离散事件仿真引擎,使用`RealtimeEnvironment`实现实时仿真
- **python-can**: CAN总线协议仿真库
- **asyncio + threading**: 异步I/O与多线程结合,SimPy在独立线程运行
- **Pydantic V2**: 数据模型校验与序列化

**前端核心技术**:
- **Vue 3 Composition API**: 组合式函数实现模块化逻辑
- **AntV X6 (XflowDAG)**: 拓扑图可视化与编辑
- **ECharts 5.5.1**: 带宽图表、负载曲线实时渲染
- **vue-virtual-scroller**: 报文列表虚拟滚动,支持10万+条数据
- **WebSocket**: 实时双向通信,推送报文、带宽、告警数据
- **WebWorker**: 数据预处理在后台线程执行

### 核心功能模块

1. **仿真会话管理**: 创建、启动、暂停、恢复、停止,支持速度调节(0.1x ~ 10x)
2. **协议仿真引擎**: 基于SimPy的高保真协议模拟,支持MIL-STD-1553B、CAN、RS422/RS485、LAN
3. **实时报文监控**: WebSocket推送报文数据,前端虚拟滚动展示,支持过滤、搜索、导出
4. **带宽分析**: 实时计算各端口带宽,绘制带宽曲线,检测带宽溢出
5. **告警检测**: 静态告警(拓扑验证)+ 动态告警(负载、冲突、丢包),分级展示
6. **故障注入**: 支持丢包、延迟、位翻转等故障模拟,验证系统容错能力
7. **事件触发**: 基于时间或条件触发特定事件,模拟复杂场景
8. **仿真报告**: 生成仿真会话报告,包含报文统计、带宽分析、告警汇总

### 架构设计亮点

#### 后端架构特色
- **多线程隔离**: SimPy仿真运行在独立线程(`SimulationRunner`),通过`command_queue`与FastAPI主线程通信,避免阻塞异步事件循环
- **插件化协议模型**: 所有协议继承`BaseProtocolModel`,遵循统一接口,新增协议只需实现`start_processes`和`emit_message`方法
- **增量数据推送**: 通过WebSocket推送增量数据(新报文、带宽变化、新告警),减少网络传输量
- **数据清理策略**: 
  - 报文数据保留最近10,000条
  - 带宽数据保留最近1,000个时间点
  - 告警数据保留最近500条
  - 通过`maxlen`参数的`deque`实现循环缓冲区

#### 前端架构特色
- **Composables模块化**: 14个Composables文件,每个封装独立功能(如`useSimulationControl`、`useSimulationWebSocket`)
- **组件层次化**: 主页面`index.vue`作为容器,集成10+个功能组件(如`BandwidthChartPanel`、`AlarmPanelFloating`)
- **性能优化**:
  - 报文列表使用`vue-virtual-scroller`,仅渲染可见行
  - 带宽图表使用`debounce`防抖,避免频繁重绘
  - 节点编辑使用`throttle`节流,减少API调用
- **状态管理**: Pinia Store管理全局状态(如当前拓扑、仿真状态),Composables管理局部状态

### 协议仿真详细设计

#### MIL-STD-1553B协议
- **总线角色**: BC(总线控制器)、RT(远程终端)
- **时序参数**:
  - BC命令间隔: 10μs
  - RT响应时间: 4~12μs
  - 帧间隔: 最小4μs
- **仿真逻辑**:
  - BC周期性发送BC-RT命令
  - RT接收到命令后,延迟`response_time`后发送响应
  - 使用SimPy的`yield env.timeout()`模拟时序

#### CAN总线协议
- **帧格式**: 标准帧(11-bit ID)、扩展帧(29-bit ID)
- **仲裁机制**: ID越小优先级越高
- **波特率**: 125K、250K、500K、1000K
- **仿真逻辑**:
  - 每个节点独立进程,按`period`发送CAN帧
  - 模拟总线仲裁(多个节点同时发送时,ID小的优先)
  - 计算帧传输时间: `frame_length / bitrate`

#### RS422/RS485协议
- **通信参数**: 波特率(9.6K~921.6K)、数据位(5~8)、停止位(1~2)、校验位(None/Odd/Even)
- **仿真逻辑**:
  - 串行字节传输
  - 计算字节传输时间: `(1 + data_bits + parity + stop_bits) / baudrate`
  - RS485支持多主机,模拟总线竞争

#### LAN以太网协议
- **传输方式**: UDP单播/组播/广播、TCP连接
- **速率**: 10M、100M、1000M
- **仿真逻辑**:
  - 计算帧传输时间: `(frame_length + 26 bytes) * 8 / speed`
  - UDP模拟无连接发送
  - TCP模拟三次握手与可靠传输

- 本文档遵循语义化版本号: `主版本.次版本.修订版`
- 重大变更(架构调整、接口变更)更新主版本号
