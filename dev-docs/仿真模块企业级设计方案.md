## 一、仿真模块概述

### 1.1 模块定位与价值

仿真模块是多总线混合设计仿真管理系统的**核心功能模块**,承担以下关键职责:

1. **设计验证**: 在硬件实现前验证多总线拓扑的正确性和性能指标
2. **风险预测**: 通过仿真提前发现带宽瓶颈、冲突、环路等设计缺陷
3. **容错测试**: 通过故障注入验证系统在异常情况下的鲁棒性
4. **成本优化**: 减少物理原型迭代次数,降低开发成本和周期

**核心价值**:
- **提前发现问题**: 80%的设计问题可在仿真阶段发现
- **加速开发周期**: 相比硬件测试,仿真周期缩短60%
- **降低开发成本**: 减少原型制作和硬件调试成本
- **提升产品质量**: 通过充分验证提高系统可靠性

### 1.2 核心功能清单

#### 1.2.1 仿真会话管理
- ✅ 创建仿真会话(基于项目版本)
- ✅ 启动/暂停/恢复/停止仿真
- ✅ 速度调节(0.5x ~ 4x,实时生效)
- ✅ 单步执行(调试模式)
- ✅ 会话状态持久化

#### 1.2.2 协议仿真引擎
- ✅ **MIL-STD-1553B**: BC-RT通信、总线仲裁、时序精确模拟
- ✅ **CAN总线**: ID仲裁、帧格式(标准/扩展)、错误检测
- ✅ **RS422/RS485**: UART串行通信、波特率计算
- ✅ **LAN以太网**: UDP单播/组播/广播、TCP连接模拟

#### 1.2.3 实时数据监控
- ✅ **报文监控**: WebSocket实时推送,虚拟滚动展示10万+条报文
- ✅ **带宽分析**: 实时计算各端口带宽,绘制带宽曲线
- ✅ **负载统计**: 端口负载率、报文计数、丢包统计
- ✅ **拓扑动画**: 报文流动光点动画,可视化数据流向

#### 1.2.4 告警检测
- ✅ **静态告警**: 拓扑验证(环路检测、多连检测、协议不匹配)
- ✅ **动态告警**: 带宽溢出、负载过高、报文冲突、丢包告警
- ✅ **告警分级**: 严重/警告/提示,支持过滤和导出
- ✅ **告警历史**: 记录所有告警事件,支持回溯分析

#### 1.2.5 故障注入与事件触发
- ✅ **故障类型**: 丢包、延迟、位翻转、连接中断
- ✅ **注入时机**: 基于时间或条件触发
- ✅ **影响范围**: 支持单链路或全局故障
- ✅ **事件触发**: 自定义事件在特定时刻触发

#### 1.2.6 仿真报告
- ✅ 生成会话报告(报文统计、带宽分析、告警汇总)

### 1.3 技术挑战与解决方案

| 技术挑战 | 解决方案 | 效果 |
|---------|---------|------|
| **SimPy阻塞运行与FastAPI异步冲突** | 使用`SimulationRunner`在独立线程运行SimPy,通过`command_queue`通信 | 完全解耦,互不阻塞 |
| **高频报文推送导致前端卡顿** | 增量推送 + 虚拟滚动 + 防抖节流 | 支持10万+条报文流畅展示 |

| **多协议并发仲裁复杂** | 基于SimPy Resource实现总线仲裁 | 正确模拟总线竞争 |
| **实时性与准确性平衡** | RealtimeEnvironment + factor调速 | 可在实时性和精度间平衡 |

## 二、仿真引擎架构设计

### 2.1 总体架构设计

系统采用**前后端分离 + WebSocket实时通信**的架构,后端使用**SimPy离散事件仿真**作为核心引擎。

```
┌─────────────────────────────────────────────────────────────────┐
│                         前端层 (Vue 3)                           │
├─────────────────────────────────────────────────────────────────┤

│  AlarmPanel        │  MessageMonitor        │  EventTrigger      │
├─────────────────────────────────────────────────────────────────┤
│  Composables (组合式函数)                                        │
│  - useSimulationControl   - useSimulationWebSocket              │
│  - useTopologyAnimation   - useFaultInjection                   │
└─────────────────────────────────────────────────────────────────┘
                              ↕ HTTP / WebSocket
┌─────────────────────────────────────────────────────────────────┐
│                       后端层 (FastAPI)                           │
├─────────────────────────────────────────────────────────────────┤
│  SimulationController (REST API + WebSocket)                    │
│    ↓                                                             │
│  SimulationService (会话管理)                                   │
│    ↓                                                             │
│  SimulationEngine (仿真引擎核心)                                │
│    ├─ SimulationRunner (SimPy线程运行器)                        │
│    ├─ BandwidthCalculator (带宽计算器)                          │
│    ├─ AlarmDetector (告警检测器)                                │

│    └─ ProtocolModels (协议模型)                                 │
│         ├─ BaseProtocolModel (协议基类)                         │
│         ├─ MIL1553BModel (1553B协议)                            │

│         ├─ RS485Model (RS485协议)                               │
│         └─ LANModel (LAN协议)                                   │
└─────────────────────────────────────────────────────────────────┘
                              ↕
┌─────────────────────────────────────────────────────────────────┐
│                      数据层 (MySQL + Redis)                      │

└─────────────────────────────────────────────────────────────────┘
```

**架构特点**:
1. **分层解耦**: Controller(接口层) → Service(业务层) → Engine(引擎层) → SimPy(仿真内核)
2. **线程隔离**: SimPy运行在独立线程(`SimulationRunner`),避免阻塞FastAPI异步循环
3. **实时通信**: WebSocket推送增量数据,降低网络开销
4. **插件化协议**: 所有协议继承`BaseProtocolModel`,易于扩展

### 2.2 SimPy离散事件仿真引擎

#### 2.2.1 SimPy简介

**SimPy**是Python的离散事件仿真(DES)框架,核心概念:
- **Environment**: 仿真环境,维护事件队列和仿真时钟
- **Process**: 进程,使用Python生成器定义行为
- **Resource**: 资源,模拟有限容量的共享资源(如总线)
- **Timeout**: 延时事件,模拟时间推进

**优势**:
- ✅ 精确的时序模拟(微秒级)
- ✅ 基于事件驱动,避免时间步进循环的低效
- ✅ 天然支持资源竞争和排队模型
- ✅ `RealtimeEnvironment`支持实时同步

#### 2.2.2 RealtimeEnvironment实时同步

```python
import simpy.rt

# 创建实时环境,factor=1.0表示仿真时钟与墙钟时间1:1同步
env = simpy.rt.RealtimeEnvironment(factor=1.0, strict=False)

# factor=2.0: 仿真以2倍速运行(仿真1秒对应现实0.5秒)
# factor=0.5: 仿真以0.5倍速运行(仿真1秒对应现实2秒)
# strict=False: 允许仿真滞后(如计算耗时大于实时要求)
```

**应用场景**:
- `factor=1.0`: 实时仿真,用于演示和人机交互
- `factor>1.0`: 加速仿真,快速验证长时间运行场景
- `factor<1.0`: 慢速仿真,便于调试和观察细节

### 2.3 多线程运行架构

#### 2.3.1 SimulationRunner设计

**问题**: SimPy的`env.run()`是阻塞调用,会阻塞FastAPI的异步事件循环,导致HTTP请求无法响应。

**解决方案**: 将SimPy运行在独立线程中,通过线程安全的`Queue`与主线程通信。

```
┌─────────────────────────────────────────────────────────────┐
│                      主线程 (FastAPI)                        │
│  ┌───────────────────────────────────────────────────────┐  │
│  │  SimulationController                                 │  │
│  │    ↓                                                  │  │
│  │  SimulationService                                    │  │
│  │    ↓                                                  │  │
│  │  SimulationEngine                                     │  │
│  └───────────────────────────────────────────────────────┘  │
│                    ↕ command_queue (线程安全)                │
└─────────────────────────────────────────────────────────────┘
                              ↕
┌─────────────────────────────────────────────────────────────┐
│                   仿真线程 (SimulationRunner)                │
│  ┌───────────────────────────────────────────────────────┐  │
│  │  SimPy RealtimeEnvironment                            │  │
│  │    ├─ BC Process (1553B总线控制器)                   │  │
│  │    ├─ RT Process (1553B远程终端)                     │  │
│  │    ├─ CAN Node Process (CAN节点)                     │  │
│  │    ├─ UART Process (串口通信)                        │  │
│  │    └─ LAN Process (以太网)                           │  │
│  └───────────────────────────────────────────────────────┘  │
│                    ↑ tick_callback (数据推送)               │
└─────────────────────────────────────────────────────────────┘
```

**核心代码**:

```python
class SimulationRunner(threading.Thread):
    """
    仿真运行器
    在独立线程中运行 RealtimeEnvironment
    """
    
    def __init__(self, session_id, topology_data, tick_callback, speed=1.0):
        super().__init__(daemon=True)
        self.session_id = session_id
        self.topology_data = topology_data
        self.tick_callback = tick_callback  # 每个时间片回调
        
        # 控制信号(线程安全)
        self._paused = threading.Event()
        self._stopped = threading.Event()
        self._paused.set()  # 初始为运行状态
        
        # 指令队列
        self.command_queue = Queue()
        
        # 创建SimPy环境
        self.env = simpy.rt.RealtimeEnvironment(factor=speed, strict=False)
    
    def run(self):
        """主循环"""
        self._setup_world()  # 创建进程和资源
        last_emit = time.time()
        
        while not self._stopped.is_set():
            # 处理控制指令
            self._process_commands()
            
            # 如果暂停,等待恢复
            if not self._paused.is_set():
                time.sleep(0.05)
                continue
            
            # 推进仿真(小步进,便于响应控制指令)
            step_size = min(0.1, 0.05)
            self.env.run(until=self.env.now + step_size)
            
            # 定期回调(推送数据)
            now = time.time()
            if now - last_emit >= 0.1:  # 每100ms推送一次
                self.tick_callback(self.env.now)
                last_emit = now
    
    def pause(self):
        """暂停仿真"""
        self._paused.clear()
    
    def resume(self):
        """继续仿真"""
        self._paused.set()
    
    def stop(self):
        """停止仿真"""
        self._stopped.set()
        self._paused.set()
    
    def set_speed(self, speed: float):
        """调节速度(通过指令队列)"""
        self.command_queue.put(("speed", speed))
    
    def _process_commands(self):
        """处理控制指令"""
        try:
            while not self.command_queue.empty():
                cmd, value = self.command_queue.get_nowait()
                if cmd == "speed":
                    self.env.factor = max(0.5, min(value, 4.0))
                elif cmd == "step":
                    self.env.run(until=self.env.now + 0.1)
        except Empty:
            pass
    
    def _setup_world(self):
        """创建SimPy进程和资源(协议模型实现)"""
        # 解析拓扑,创建进程...
        pass
```

**关键设计**:
1. **线程隔离**: SimPy在daemon线程中运行,主线程不受阻塞
2. **指令队列**: 通过`Queue`传递pause/resume/stop/speed等指令,线程安全
3. **回调机制**: 通过`tick_callback`将仿真数据推送回主线程,再通过WebSocket发送给前端
4. **小步进**: 每次推进0.05~0.1秒,确保控制指令能快速响应

### 2.4 协议模型插件化设计

#### 2.4.1 BaseProtocolModel基类

所有协议模型继承统一基类,遵循相同接口:

```python
from abc import ABC, abstractmethod
from typing import List, Dict, Any
import simpy

class BaseProtocolModel(ABC):
    """
    协议模型基类
    所有协议(1553B/CAN/RS485/LAN)必须继承此类
    """
    
    def __init__(self, env: simpy.Environment, node_id: str, config: Dict[str, Any]):
        """
        初始化协议模型
        
        参数:
            env: SimPy环境
            node_id: 节点ID
            config: 协议配置(包含协议参数、报文列表等)
        """
        self.env = env
        self.node_id = node_id
        self.config = config
        self.messages: List[Dict] = []  # 发送的报文列表
    
    @abstractmethod
    def start_processes(self) -> List[simpy.Process]:
        """
        启动协议进程
        
        返回:
            SimPy进程列表
        """
        pass
    
    @abstractmethod
    def emit_message(self, target_id: str, data: bytes) -> None:
        """
        发送报文
        
        参数:
            target_id: 目标节点ID
            data: 报文数据
        """
        pass
    
    def get_messages(self) -> List[Dict]:
        """
        获取已发送的报文列表
        
        返回:
            报文列表[{timestamp, source, target, data, ...}]
        """
        return self.messages
```

**优势**:
- ✅ 统一接口,便于Engine调用
- ✅ 新增协议只需实现`start_processes`和`emit_message`
- ✅ 易于单元测试和Mock

#### 2.4.2 协议模型工厂

```python
from typing import Dict, Type

PROTOCOL_MODEL_REGISTRY: Dict[str, Type[BaseProtocolModel]] = {
    "MIL-STD-1553B": MIL1553BModel,
    "CAN": CANBusModel,
    "RS485": RS485Model,
    "RS422": RS485Model,  # RS422复用RS485模型
    "LAN": LANModel,
}

def create_protocol_model(protocol_type: str, env, node_id, config) -> BaseProtocolModel:
    """
    根据协议类型创建协议模型实例
    
    参数:
        protocol_type: 协议类型(如"CAN")
        env: SimPy环境
        node_id: 节点ID
        config: 协议配置
    
    返回:
        协议模型实例
    """
    model_class = PROTOCOL_MODEL_REGISTRY.get(protocol_type)
    if not model_class:
        raise ValueError(f"Unsupported protocol: {protocol_type}")
    return model_class(env, node_id, config)
```

#### 2.5.2 状态机设计

仿真会话生命周期:

```
        create_session()
             ↓
    ┌─────[created]─────┐
    │                   │
    │  start()          │
    │   ↓               │
    │ [running]◀────────┤
    │   ↓  ↑            │
    │   │  │ resume()   │
    │ pause()           │
    │   ↓  │            │
    │ [paused]          │
    │   ↓               │
    │ stop()            │
    │   ↓               │
    └─▶[stopped]◀───────┘
```

**状态转换规则**:
- `created` → `running`: 调用`start()`
- `running` → `paused`: 调用`pause()`
- `paused` → `running`: 调用`resume()`
- `running/paused` → `stopped`: 调用`stop()`
- `stopped`: 终态,无法恢复

#### 4.2.2 useSimulationControl设计

**职责**: 管理仿真会话的生命周期和状态

```typescript
// useSimulationControl.js
import { ref, computed } from 'vue'
import { simulationApi } from '@/api/project/simulation'

export function useSimulationControl(versionId) {
  // 状态定义
  const SimulationStatus = {
    IDLE: 'idle',       // 未创建
    CREATED: 'created', // 已创建,未启动
    RUNNING: 'running', // 运行中
    PAUSED: 'paused',   // 已暂停
    STOPPED: 'stopped'  // 已停止
  }
  
  const sessionId = ref(null)
  const status = ref(SimulationStatus.IDLE)
  const elapsedTime = ref(0)
  const speed = ref(1.0)
  
  // 计算属性
  const isRunning = computed(() => status.value === SimulationStatus.RUNNING)
  const isPaused = computed(() => status.value === SimulationStatus.PAUSED)
  const canStart = computed(() => [SimulationStatus.IDLE, SimulationStatus.CREATED, SimulationStatus.STOPPED].includes(status.value))
  const canPause = computed(() => status.value === SimulationStatus.RUNNING)
  const canResume = computed(() => status.value === SimulationStatus.PAUSED)
  const canStop = computed(() => [SimulationStatus.RUNNING, SimulationStatus.PAUSED].includes(status.value))
  
  // 创建会话
  async function createSession() {
    const res = await simulationApi.createSession({ versionId: versionId.value })
    sessionId.value = res.data.sessionId
    status.value = SimulationStatus.CREATED
    return sessionId.value
  }
  
  // 启动仿真
  async function handleStart() {
    if (!sessionId.value) {
      await createSession()
    }
    await simulationApi.startSession(sessionId.value)
    status.value = SimulationStatus.RUNNING
  }
  
  // 暂停仿真
  async function handlePause() {
    await simulationApi.pauseSession(sessionId.value)
    status.value = SimulationStatus.PAUSED
  }
  
  // 恢复仿真
  async function handleResume() {
    await simulationApi.resumeSession(sessionId.value)
    status.value = SimulationStatus.RUNNING
  }
  
  // 停止仿真
  async function handleStop() {
    await simulationApi.stopSession(sessionId.value)
    status.value = SimulationStatus.STOPPED
  }
  
  // 调节速度
  async function handleSpeedChange(newSpeed) {
    await simulationApi.setSpeed(sessionId.value, newSpeed)
    speed.value = newSpeed
  }
  
  // 单步执行
  async function handleStep() {
    await simulationApi.stepSession(sessionId.value)
  }
  
  return {
    // 状态
    sessionId,
    status,
    elapsedTime,
    speed,
    // 计算属性
    isRunning,
    isPaused,
    canStart,
    canPause,
    canResume,
    canStop,
    // 方法
    createSession,
    handleStart,
    handlePause,
    handleResume,
    handleStop,
    handleSpeedChange,
    handleStep,
    SimulationStatus
  }
}
```

#### 4.2.3 useSimulationWebSocket设计

**职责**: 管理WebSocket连接,接收实时数据推送

```typescript
// useSimulationWebSocket.js
import { ref, onUnmounted, watch } from 'vue'

export function useSimulationWebSocket(sessionId) {
  const ws = ref(null)
  const connected = ref(false)
  
  // 数据缓存
  const messages = ref([])       // 报文列表
  const bandwidthData = ref([])  // 带宽数据
  const alarms = ref([])         // 告警列表
  
  // 连接WebSocket
  function connect() {
    const wsUrl = `ws://localhost:8000/ws/simulation/${sessionId.value}`
    ws.value = new WebSocket(wsUrl)
    
    ws.value.onopen = () => {
      connected.value = true
      console.log('WebSocket connected')
    }
    
    ws.value.onmessage = (event) => {
      const data = JSON.parse(event.data)
      handleMessage(data)
    }
    
    ws.value.onerror = (error) => {
      console.error('WebSocket error:', error)
    }
    
    ws.value.onclose = () => {
      connected.value = false
      console.log('WebSocket disconnected')
      // 自动重连
      setTimeout(() => {
        if (sessionId.value) connect()
      }, 3000)
    }
  }
  
  // 处理接收到的消息
  function handleMessage(data) {
    if (data.type === 'message') {
      // 增量推送报文
      messages.value.push(...data.messages)
      // 限制最大数量
      if (messages.value.length > 10000) {
        messages.value.splice(0, messages.value.length - 10000)
      }
    } else if (data.type === 'bandwidth') {
      // 增量推送带宽数据
      bandwidthData.value.push(...data.bandwidth)
      // 限制最大数量
      if (bandwidthData.value.length > 6000) {
        bandwidthData.value.splice(0, bandwidthData.value.length - 6000)
      }
    } else if (data.type === 'alarm') {
      // 增量推送告警
      alarms.value.push(...data.alarms)
    }
  }
  
  // 断开连接
  function disconnect() {
    if (ws.value) {
      ws.value.close()
      ws.value = null
    }
  }
  
  // 监听sessionId变化
  watch(sessionId, (newId) => {
    if (newId) {
      connect()
    } else {
      disconnect()
    }
  }, { immediate: true })
  
  // 组件卸载时断开连接
  onUnmounted(() => {
    disconnect()
  })
  
  return {
    connected,
    messages,
    bandwidthData,
    alarms,
    connect,
    disconnect
  }
}
```

let heartbeatTimer = null

function startHeartbeat() {
  heartbeatTimer = setInterval(() => {
    if (ws.value && connected.value) {
      ws.value.send(JSON.stringify({ type: 'ping' }))
    }
  }, 30000) // 每30秒发送一次心跳
}

function stopHeartbeat() {
  if (heartbeatTimer) {
    clearInterval(heartbeatTimer)
    heartbeatTimer = null
  }
}

let reconnectAttempts = 0
const maxReconnectAttempts = 5

function reconnect() {
  if (reconnectAttempts < maxReconnectAttempts) {
    reconnectAttempts++
    console.log(`尝试重连 (${reconnectAttempts}/${maxReconnectAttempts})`)
    setTimeout(() => {
      connect()
    }, 3000 * reconnectAttempts) // 指数退避
  } else {

#### 5.2.1 ConnectionManager设计

```python
from typing import Dict, List
from fastapi import WebSocket

class ConnectionManager:
    """
    WebSocket连接管理器
    管理多个会话的WebSocket连接
    """
    
    def __init__(self):
        # {session_id: [websocket1, websocket2, ...]}
        self.active_connections: Dict[str, List[WebSocket]] = {}
    
    async def connect(self, websocket: WebSocket, session_id: str):
        """
        连接WebSocket
        
        参数:
            websocket: WebSocket连接
            session_id: 会话ID
        """
        await websocket.accept()
        if session_id not in self.active_connections:
            self.active_connections[session_id] = []
        self.active_connections[session_id].append(websocket)
    
    def disconnect(self, websocket: WebSocket, session_id: str):
        """
        断开WebSocket
        
        参数:
            websocket: WebSocket连接
            session_id: 会话ID
        """
        if session_id in self.active_connections:
            self.active_connections[session_id].remove(websocket)
            if not self.active_connections[session_id]:
                del self.active_connections[session_id]
    
    async def broadcast(self, session_id: str, message: dict):
        """
        向指定会话的所有连接广播消息
        
        参数:
            session_id: 会话ID
            message: 消息内容
        """
        if session_id in self.active_connections:
            for connection in self.active_connections[session_id]:
                await connection.send_json(message)
    
    async def send_personal(self, websocket: WebSocket, message: dict):
        """
        向单个连接发送消息
        
        参数:
            websocket: WebSocket连接
            message: 消息内容
        """
        await websocket.send_json(message)
```

#### 5.5.1 MIL-STD-1553B协议模型

```python
class MIL1553BModel(BaseProtocolModel):
    """
    MIL-STD-1553B 协议模型
    支持 BC-RT、RT-BC、RT-RT 通信
    """
    
    def __init__(self, env, node_id, config):
        super().__init__(env, node_id, config)
        self.role = config.get('role')  # 'BC' or 'RT'
        self.rt_address = config.get('rt_address') if self.role == 'RT' else None
        self.schedule = config.get('schedule', [])  # BC调度表
    
    def start_processes(self) -> List[simpy.Process]:
        """启动进程"""
        if self.role == 'BC':
            return [self.env.process(self._bc_process())]
        elif self.role == 'RT':
            return [self.env.process(self._rt_process())]
        return []
    
    def _bc_process(self):
        """BC进程 - 周期性发送命令"""
        while True:
            for frame in self.schedule:
                # 发送BC-RT命令
                rt_address = frame['rt_address']
                subaddress = frame['subaddress']
                word_count = frame['word_count']
                
                # 构造命令字
                command_word = self._build_command_word(rt_address, subaddress, word_count)
                
                # 发送命令
                self.emit_message(f"RT_{rt_address}", command_word)
                
                # 等待RT响应(12μs响应时间)
                yield self.env.timeout(0.000012)
                
                # 帧间隔(10μs)
                yield self.env.timeout(0.00001)
            
            # 主帧周期
            yield self.env.timeout(self.config.get('major_frame_time', 0.01))
    
    def _rt_process(self):
        """RT进程 - 响应BC命令"""
        while True:
            # 监听总线(模拟)
            # 实际实现中需要通过SimPy的Store或Pipe接收命令
            yield self.env.timeout(0.001)  # 监听周期
            
            # 如果收到匹配地址的命令,发送状态字
            # self.emit_message('BC', status_word)
    
    def emit_message(self, target_id: str, data: bytes):
        """发送报文"""
        message = {
            'id': f"msg_{uuid.uuid4().hex[:8]}",
            'timestamp': self.env.now,
            'source': self.node_id,
            'target': target_id,
            'protocol': 'MIL-STD-1553B',
            'size': len(data),
            'data': data.hex()
        }
        self.messages.append(message)
    
    def _build_command_word(self, rt_address, subaddress, word_count):
        """构造1553B命令字"""
        # 命令字格式: [同步头(3bit)][RT地址(5bit)][T/R(1bit)][子地址(5bit)][字数(5bit)][奇偶校验(1bit)]
        # 简化实现
        return bytes([rt_address, subaddress, word_count])
```

import can

class CANBusModel(BaseProtocolModel):
    """
    CAN总线协议模型
    基于python-can库实现
    """
    
    def __init__(self, env, node_id, config):
        super().__init__(env, node_id, config)
        self.bitrate = config.get('bitrate', 500000)  # 500Kbps
        self.messages_config = config.get('messages', [])
        
        # 创建虚拟CAN通道
        self.bus = can.interface.Bus(
            channel='virtual',
            bustype='virtual',
            bitrate=self.bitrate
        )
    
    def start_processes(self) -> List[simpy.Process]:
        """启动CAN节点进程"""
        processes = []
        for msg_cfg in self.messages_config:
            processes.append(self.env.process(self._send_periodic(msg_cfg)))
        return processes
    
    def _send_periodic(self, msg_cfg):
        """周期性发送CAN报文"""
        can_id = msg_cfg['can_id']
        period = msg_cfg['period']  # 周期(秒)
        data_length = msg_cfg['data_length']
        
        while True:
            # 生成CAN帧
            msg = can.Message(
                arbitration_id=can_id,
                data=bytes(range(data_length)),
                is_extended_id=False
            )
            
            # 发送
            self.bus.send(msg)
            
            # 记录报文
            self.emit_message('broadcast', msg.data)
            
            # 等待周期
            yield self.env.timeout(period)
    
    def emit_message(self, target_id: str, data: bytes):
        """记录CAN报文"""
        message = {
            'id': f"msg_{uuid.uuid4().hex[:8]}",
            'timestamp': self.env.now,
            'source': self.node_id,
            'target': target_id,
            'protocol': 'CAN',
            'size': len(data),
            'data': data.hex()
        }
        self.messages.append(message)
