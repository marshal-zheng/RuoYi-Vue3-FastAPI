## 核心内容概览

### 技术架构

**后端技术栈**:
- FastAPI 0.115.8 (高性能Web框架)
- SQLAlchemy 2.0.38 (异步ORM)
- MySQL 8.0 / PostgreSQL (主数据库)
- Redis 5.0+ (缓存)
- PyJWT (JWT认证)
- APScheduler (定时任务)

**前端技术栈**:
- Vue 3 (组合式API)
- TypeScript 5.9+
- Element Plus 2.7.6 (UI组件库)
- Pinia 2.1.7 (状态管理)
- AntV X6 (拓扑图编辑)
- ECharts 5.5.1 (数据可视化)

### 核心功能模块

1. **工程管理**: 项目全生命周期管理、多版本并行开发、版本固化与克隆、拓扑图形化设计
2. **设备中心**: 设备分类管理、设备模型库、设备接口配置、报文配置
3. **协议管理**: 多总线协议支持(LAN/RS422/RS485/CAN/1553B)、协议模板化、协议固化
4. **仿真功能**: 实时仿真、报文监控、带宽分析、告警检测、数据注入
5. **系统管理**: 用户管理、角色管理、菜单管理、操作日志、登录日志

### 数据库设计亮点

- **JSON字段**: 使用JSON字段存储拓扑数据、协议配置等复杂结构
- **软删除**: 核心业务表使用`del_flag`字段实现逻辑删除
- **索引优化**: 为高频查询字段添加索引,提升查询性能
- **分区表**: 日志表按月分区,便于归档和清理
- **外键约束**: 使用外键保证数据一致性

### 接口设计特色

- **RESTful风格**: 遵循REST架构原则,语义清晰
- **统一响应格式**: 标准化的JSON响应格式
- **JWT认证**: 无状态认证,支持分布式部署
- **RBAC权限**: 基于角色的访问控制,细粒度权限管理
- **接口文档**: FastAPI自动生成OpenAPI文档

### 部署方案

- **Docker容器化**: 一键部署,环境隔离
- **负载均衡**: 支持多实例水平扩展
- **数据库主从**: MySQL主从复制,读写分离
- **Redis缓存**: 热点数据缓存,提升性能
- **日志监控**: 完善的日志系统和监控告警
