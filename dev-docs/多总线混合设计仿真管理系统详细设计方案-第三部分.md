# 多总线混合设计仿真管理系统详细设计方案(第三部分)

## 八、数据库设计

### 8.1 数据库概述

#### 8.1.1 数据库选型

- **主数据库**: MySQL 8.0
  - 优势: 成熟稳定、性能优秀、JSON字段支持、事务ACID保证
  - 用途: 存储结构化数据(用户、角色、菜单、工程、设备、协议等)

- **缓存数据库**: Redis 5.0+
  - 优势: 高性能、支持多种数据结构
  - 用途: 缓存字典数据、用户权限、会话管理

#### 8.1.2 数据库命名规范

- 表名: 小写字母+下划线,前缀`sys_`表示系统表
- 字段名: 小写字母+下划线
- 主键: `{表名}_id`
- 外键: `{关联表名}_id`
- 索引: `idx_{字段名}` (普通索引) / `uk_{字段名}` (唯一索引)
- 时间字段: `create_time`(创建时间) / `update_time`(更新时间)
- 软删除字段: `del_flag` (0-存在, 2-删除)

#### 8.1.3 字段类型规范

| 类型 | 字段类型 | 说明 |
|------|----------|------|
| 主键 | BIGINT(20) AUTO_INCREMENT | 自增主键 |
| 外键 | BIGINT(20) | 关联其他表主键 |
| 字符串(短) | VARCHAR(50) | 名称、编码等 |
| 字符串(长) | VARCHAR(500) | 描述、备注等 |
| 文本 | TEXT / LONGTEXT | 大文本内容 |
| JSON | JSON | 复杂结构数据 |
| 日期时间 | DATETIME | 时间字段 |
| 状态标志 | CHAR(1) | 状态(0/1) |
| 布尔 | TINYINT(1) | 是/否 |

```python
    """业务异常"""
    def __init__(self, message: str, code: int = 500):
        self.message = message
        self.code = code

@app.exception_handler(BusinessException)
async def business_exception_handler(request, exc: BusinessException):
    return JSONResponse(
        status_code=200,
        content={"code": exc.code, "msg": exc.message, "data": None}
    )

@app.exception_handler(Exception)
async def global_exception_handler(request, exc: Exception):
    logger.error(f"系统异常: {str(exc)}", exc_info=True)
    return JSONResponse(
        status_code=500,
        content={"code": 500, "msg": "系统异常", "data": None}
    )
```
