## 手动操作步骤

如果需要手动执行或了解详细步骤，可以按照以下步骤操作：

### 1. 删除并重建数据库

```bash
mysql -u root -padmin1234 -e "DROP DATABASE IF EXISTS \`ruoyi-fastapi\`; CREATE DATABASE \`ruoyi-fastapi\` CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
```

**说明**：
- 删除现有的 `ruoyi-fastapi` 数据库（如果存在）
- 重新创建数据库，使用 `utf8mb4` 字符集和 `utf8mb4_unicode_ci` 排序规则

### 2. 导入所有 SQL 脚本（按顺序）

按照 Docker Compose 配置的顺序，依次导入所有模块的 SQL 脚本：

```bash
# 1. 基础系统（必须最先导入）
mysql -u root -padmin1234 ruoyi-fastapi < ruoyi-fastapi-backend/sql/ruoyi-fastapi.sql

# 2. 工程/项目模块
mysql -u root -padmin1234 ruoyi-fastapi < ruoyi-fastapi-backend/sql/project.sql

# 3. 设备模块
mysql -u root -padmin1234 ruoyi-fastapi < ruoyi-fastapi-backend/sql/device.sql

# 4. 协议模块
mysql -u root -padmin1234 ruoyi-fastapi < ruoyi-fastapi-backend/sql/protocol.sql

# 5. 仿真模块
mysql -u root -padmin1234 ruoyi-fastapi < ruoyi-fastapi-backend/sql/simulation.sql
```

**说明**：
- **必须按顺序导入**：基础系统脚本必须先执行，其他模块脚本依赖基础表结构
- 所有模块脚本都具备幂等性，可重复执行，自动补齐菜单、字典和管理员权限
- 导入顺序与 Docker Compose 配置中的顺序一致（00-04）

### 3. 更新管理员密码

生成 BCrypt 密码哈希并更新到数据库：

```bash
python3 -c "import bcrypt; hash_pwd = bcrypt.hashpw('admin123'.encode('utf-8'), bcrypt.gensalt()).decode('utf-8'); print(hash_pwd)" | xargs -I {} mysql -u root -padmin1234 ruoyi-fastapi -e "UPDATE sys_user SET password = '{}' WHERE user_name = 'admin';"
```

**说明**：
- 使用 Python 生成 `admin123` 的 BCrypt 哈希值
- 将生成的哈希值更新到 `sys_user` 表中 `user_name='admin'` 的记录

### 4. 验证密码设置

验证密码是否正确设置：

```bash
mysql -u root -padmin1234 ruoyi-fastapi -e "SELECT password FROM sys_user WHERE user_name = 'admin';" | tail -1 | python3 -c "import sys, bcrypt; pwd_hash = sys.stdin.read().strip(); result = bcrypt.checkpw('admin123'.encode('utf-8'), pwd_hash.encode('utf-8')); print('✅ 密码验证成功' if result else '❌ 密码验证失败')"
```

**说明**：
- 从数据库读取 admin 用户的密码哈希
- 使用 BCrypt 验证密码是否正确
- 输出验证结果

### 方式二：手动执行命令

如果需要手动执行，可以将以下步骤合并为一个脚本：

```bash
#!/bin/bash

# 数据库重置脚本
DB_USER="root"
DB_PASSWORD="admin1234"
DB_NAME="ruoyi-fastapi"
ADMIN_USER="admin"
ADMIN_PASSWORD="admin123"
PROJECT_ROOT="/Users/hqz/dev/RuoYi-Vue3-FastAPI"

cd "$PROJECT_ROOT"

echo "🗑️  删除现有数据库..."
mysql -u "$DB_USER" -p"$DB_PASSWORD" -e "DROP DATABASE IF EXISTS \`$DB_NAME\`; CREATE DATABASE \`$DB_NAME\` CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;" 2>/dev/null

echo "📥 导入所有 SQL 脚本..."
echo "   ↪ 00-ruoyi-fastapi.sql (基础系统)"
mysql -u "$DB_USER" -p"$DB_PASSWORD" "$DB_NAME" < ruoyi-fastapi-backend/sql/ruoyi-fastapi.sql 2>/dev/null
echo "   ↪ 01-project.sql (工程模块)"
mysql -u "$DB_USER" -p"$DB_PASSWORD" "$DB_NAME" < ruoyi-fastapi-backend/sql/project.sql 2>/dev/null
echo "   ↪ 02-device.sql (设备模块)"
mysql -u "$DB_USER" -p"$DB_PASSWORD" "$DB_NAME" < ruoyi-fastapi-backend/sql/device.sql 2>/dev/null
echo "   ↪ 03-protocol.sql (协议模块)"
mysql -u "$DB_USER" -p"$DB_PASSWORD" "$DB_NAME" < ruoyi-fastapi-backend/sql/protocol.sql 2>/dev/null
echo "   ↪ 04-simulation.sql (仿真模块)"
mysql -u "$DB_USER" -p"$DB_PASSWORD" "$DB_NAME" < ruoyi-fastapi-backend/sql/simulation.sql 2>/dev/null

echo "🔐 更新管理员密码..."
HASH_PWD=$(python3 -c "import bcrypt; print(bcrypt.hashpw('$ADMIN_PASSWORD'.encode('utf-8'), bcrypt.gensalt()).decode('utf-8'))")
mysql -u "$DB_USER" -p"$DB_PASSWORD" "$DB_NAME" -e "UPDATE sys_user SET password = '$HASH_PWD' WHERE user_name = '$ADMIN_USER';" 2>/dev/null

echo "✅ 验证密码设置..."
DB_HASH=$(mysql -u "$DB_USER" -p"$DB_PASSWORD" "$DB_NAME" -e "SELECT password FROM sys_user WHERE user_name = '$ADMIN_USER';" 2>/dev/null | tail -1)
if python3 -c "import bcrypt; import sys; result = bcrypt.checkpw('$ADMIN_PASSWORD'.encode('utf-8'), '$DB_HASH'.encode('utf-8')); sys.exit(0 if result else 1)" 2>/dev/null; then
    echo "✅ 密码验证成功！"
    echo ""
    echo "📋 登录信息："
    echo "   用户名：$ADMIN_USER"
    echo "   密码：$ADMIN_PASSWORD"
else
    echo "❌ 密码验证失败，请检查！"
fi
```

## 注意事项

1. **密码安全**：命令行中使用 `-p` 参数会在命令历史中留下密码痕迹，建议使用配置文件或环境变量
2. **数据备份**：重置数据库会删除所有现有数据，操作前请确保已备份重要数据
3. **Python 依赖**：确保系统已安装 `bcrypt` 库：`pip install bcrypt`
4. **MySQL 警告**：命令执行时可能出现 "Using a password on the command line interface can be insecure" 警告，这是正常的，不影响操作

## 常见问题

### Q: 如何修改 MySQL root 密码？

A: 如果 MySQL root 密码不是 `admin1234`，需要修改脚本中的 `DB_PASSWORD` 变量。

### Q: 如何修改管理员账号和密码？

A: 修改脚本中的 `ADMIN_USER` 和 `ADMIN_PASSWORD` 变量，然后重新执行密码更新步骤。

### Q: 密码验证失败怎么办？

A: 
1. 检查 Python 是否安装了 `bcrypt` 库
2. 确认密码哈希是否正确生成
3. 检查数据库中的密码字段是否更新成功
4. 可以手动查询数据库验证：`SELECT user_name, LEFT(password, 20) FROM sys_user WHERE user_name = 'admin';`

### Q: 导入 SQL 脚本时出现错误？

A:
1. 检查数据库是否存在：`mysql -u root -padmin1234 -e "SHOW DATABASES;"`
2. 检查 SQL 文件路径是否正确
3. 查看 MySQL 错误日志获取详细错误信息
